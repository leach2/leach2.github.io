Project Decription:
This project introduces the function of the buzzer on the Arduino LilyPad board. This feature of the board acts as a small speaker that can play single notes at a time. In this assignment, I found a song from online and pasted it into my own code to only be run when a button was pressed. 

Music Credit:
The song I used was a very elementary version of the nursery rhyme "Twinkle, Twinkle, Little Star". I liked this choice because it is easy and recognizable, making it both effective for this assignment without being too hard to integrate. I found the code for this music by searching for simple Arduino music code on Google and then navigating to a website called "Build Electronic Circuits" (https://www.build-electronic-circuits.com/arduino-buzzer/). Their code was entirely in the setup section, though, so even after copying it over I had to move some of it around to fit the criteria for this assignment. 

Code Execution:
As aforementioned, upon finding the code, it was all written in the setup section of Arduino and the loop section was empty. After copying the code over I had to paste it in the loop section and, more specifically, fit it into the button conditional. I had to make sure the code still recognized the frequencies of all the different notes defined above while also working seamlessly with the button conditional that was required for this assignment. 

Tip/Hint for Completing:
The tip I would give myself in hindsight of completing this project would be to write the code for the loop BEFORE plugging in the music. This makes it easier to identify problems with the code before considering the new content of the buzzer. I first wrote my code as just a button conditional to illuminate an LED and this helped give me confidence that the code worked before layering in the song.
