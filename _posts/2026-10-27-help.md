Project Description:
This project focuses on both the integration of the VibeBoard as well as the use of funtions outside the tradional "loop" clause. By defining these alternative functions, here called "SOS" and "RYAN", we can call upon them in the loop but store their code somewhere else, helping us stay organized and concise. In this project specifically we used this loop functions as morse code words to be played by the VibeBoard in accordance to whether or not a button was pressed. If the button was pressed, the board would vibrate the code to "SOS", but if not, the board would vibrate the code to "RYAN".


Tip/Hint for Future Self:
STAY ORGANIZED!!! When writing long lines of code it is easy to get disorganized or make mistakes that are hard to find. Using in-line comments, writing and testing small bits of code at a time, and paying attention to what error messages are saying to correct them as you go are all great strategies to help stay organized. I used all of these during this assignment which helped me complete the task effectively and efficiently.
