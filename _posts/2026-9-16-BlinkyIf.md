This assignment tasked me with writing a code to create a light-up display on the Arduino board. On the board, the light pins 5, 6, 7, & 8 were used simultaneously. At all times at least one of these lights is on, however never more than one. This was executed using modular arithmetic as well as "if" statements in the code.

The Code in Action!!!
![Red Light On](https://github.com/leach2/leach2.github.io/blob/master/assets/img/IMG_3510.jpg?raw=true)

In the future, one tip I would give myself is to find a way to keep track of previous code. Sometimes during this project, I would have a line of code that works and then edit it in a way that it no longer worked. I would try to be more conscious or screenshotting or otherwise documenting functioning code so that I when I am to experiment I can still revert to it if the experiment doesn't yield results.
