Project Decription:
This project is made to be the introduction of coding with analog arrays. In this project, we use arrays to help organize output pins and values to be randomly selected. Specifically, every second one LED pin and one brightness value will be randomly selected, matching them to illuminate that LED at that specific brightness. If, during at one of the second intervals, an LED is selected that is already illuminated, the LED will be turned off.

Tip/Hint for my Past Self:
This project really challenged me to careful in my differentiation between how functions work and how arrays work in code. Most of my error messages had to do with improper punctuation (commas, brackets, etc.) surrounding the arrays because they require different style of text. My tip would be to be especially deliberate when using arrays about how you write them into your code, and also be especially careful when reading error messages so that those errors can be fixed when something inevitably doesn't work.
