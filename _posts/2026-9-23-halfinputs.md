Description: This assignment tasked my with using either nested conditionals or logical operators in a code to turn on different color LEDs in accordance with the alignment of two boolean variables (swt & btn). Depending on the orientation combination of these two variables, of which there are only four possible outcomes, different color LEDs would be turned on. 

Nested Conditionals vs Logical Operators: For the completion of this assignment I chose to use both logical operators and nested conditionals, although for different things:
  - Logical Operators: I only used logical operators immediately after each "if" or "if else" statement. This is in the "&&" and statement because that logical operator helps connect the two boolean variables so they are read together when the code determines which color LED to illuminate
  - Nested Conditionals: The rest of the code exemplifies nested conditionals. The "if" and "if else" statements are all nested conditionals because those sections include that is only read if a specific criteria is met, otherwise known as a "conditional". 
I thought this combination of uses for these two things was smart because it helped keep my code both efficient and coherent. The lines and different sections are all easy top read and understand, but they also aren't too long or tedious which contributes to my efficiency when typing them up.
