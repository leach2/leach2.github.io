Project Description:
This project focuses on the integration of using both the light and temperature sensors in complement of the Arduino board. The code aims to record the brightness and temperature of its surroundings and turn on two red LEDs when both brightness and temperature drop below a certain threshold. In the context of the assignment, this acts as a warning when the conditions are right for ghosts to be about. 

Project Tip:
My tip from this project again would be to run code a little at a time. As it applies to this project, I think it was helpful to code either the temperature OR the light sensor first and then check to make sure that workeed before adding the other code. I also think the use of notes on the code is important to stay organized and more easily identify where the errors are occurring when things go wrong.
